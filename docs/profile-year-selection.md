# 출생연도 선택 방식 개선

신규 가입·탈퇴 후 재가입의 프로필 설정과 마이페이지 프로필 편집이 공유하는 폼의 숫자 입력을 기본 select로 변경했다. 1950년부터 앱을 연 시점의 현재 연도까지 연도별로 제공하며 최근 연도부터 표시한다. 신규 회원에게 임의의 기본 연도를 지정하지 않고 필수 선택 안내를 표시한다. 자동 완성은 bday-year를 사용한다.

기존 회원의 선택된 연도를 유지하고, 편집 화면 새로고침 시에도 서버 값을 복원한다. 기존 BE 정책상 유효한 1900~1949년 값은 해당 회원의 기존 값만 추가로 제공해 프로필 편집이 기록을 변경하지 않게 한다. 새 회원에게는 1950년 이전 선택지를 제공하지 않는다. 기존 숫자형 birthYear 요청과 BE 검증/API/DB는 변경하지 않는다.

검증: FE 자동 테스트 164개, build 및 lint 통과. 모의 API 모바일 브라우저에서 신규 가입의 미선택·필수 선택·연도 범위·숫자형 저장, 재가입, 기존 회원의 편집·저장·재진입·새로고침, 1950년 이전 기존 값 보존을 확인한다. 실제 OAuth/서버 화면 검증은 추가 패치 적용 후 확인한다.

현재 feat/24-설정-회원탈퇴 작업 브랜치에서 적용한다. 기본 dev에 직접 푸시하지 않고 테스트와 검토 후 PR로 반영한다.
