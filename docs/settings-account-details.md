# 설정 화면 후속 개선

회원 정보 카드와 계정 관리 카드를 분리했다. 회원 정보는 닉네임·가입일·소셜 로그인 방식·이메일을 본인 화면에서만 표시하며, 계정 관리 카드에서 기존 회원탈퇴 확인창으로 진입한다. 탈퇴 안내/확인/진행/오류 문구는 격식체로 통일했다.

기존 members 테이블에는 가입 시각이 없으므로 기존 회원의 가입일을 추정하지 않는다. V8은 nullable joined_at을 먼저 추가한 뒤 이후 INSERT에만 CURRENT_TIMESTAMP 기본값을 설정한다. 새 JPA 회원도 최초 저장 시 Instant를 기록하며 재로그인/프로필 수정은 이를 변경하지 않는다. 기존 회원은 null이며 '가입일 정보 없음'으로 표시한다. 한국 시간 기준 날짜로 변환한다. 과거 활동 날짜나 최초 후기 날짜를 가입일로 사용하지 않는다.

본인 MemberResponse에만 provider/email/joinedAt을 추가했다. 공개 프로필과 랭킹 DTO에는 제공하지 않는다. 등록 이메일이 없으면 '등록된 이메일 없음'을 표시하며 가입일 미제공/이전 BE 응답도 안전하게 처리한다. API의 새 필드는 추가 필드이고 기존 필드는 유지한다. 기존 V1~V7은 수정하지 않는다.

FE 테스트 164개·빌드·lint 통과. 모의 API 브라우저 검사는 기존 탈퇴 흐름과 추가 계정 정보·가입일 미확인 표시를 포함한다. H2에서 V8 SQL의 기존 행 보존/null 유지/새 가입 기본값을 확인했다. 이번 BE 변경은 Java 문법 검사까지만 수행했다. 추가한 ProfileJournalIntegrationTests 2개 및 MemberJoinedAtMigrationTests 1개는 사용자 Java 21 환경에서 실행해야 한다. 이전 BE 전체 결과(158개 중 실행 132/skip 26)는 이번 변경 전 결과이다.

회원탈퇴 범위·기존 세션 차단·재가입 정책은 기존 구현을 유지한다. 현재 검증 중인 동일 작업 브랜치에 적용하고 BE 전체/FE 테스트 및 실제 화면을 확인한 뒤 dev 대상 PR로 제출한다.
